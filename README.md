A token launch radar. It reads the sealed DefiLlama snapshot, ranks every pre-token protocol by an implied value calibrated from the live-token market, and shows a dashboard with the board, a detail view for each protocol, and the steps to farm it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
